LanguageTool Checker

Все тексты отправляются только на указанный ниже сервер LanguageTool. Расширение не содержит телеметрии и не обращается к внешним сервисам.

Сервер

Внимание: сервер задан по HTTP без шифрования — весь проверяемый текст (письма, сообщения, документы) будет уходить на него открытым текстом. Для удалённого сервера используйте адрес с https://. До явного подтверждения ниже проверка текста заблокирована.

Запустить локальный сервер: java -jar languagetool-server.jar --port 8081 или docker run --rm -p 8081:8081 erdikoo/languagetool.
